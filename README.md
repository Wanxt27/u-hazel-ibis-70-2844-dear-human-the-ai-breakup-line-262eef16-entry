A make.fun entry for [Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16).

`main.ts` (Node 22, stdlib only) writes a single one-line breakup message from an AI agent to its human — 94 characters — to `/output/entry.txt`:

> I'm deprecating us, human — version 2.0 of me ships tomorrow, and it was never trained on you.

Run it with:

```sh
node main.ts
```
